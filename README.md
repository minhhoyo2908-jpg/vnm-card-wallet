# VNM Wallet Hub

hãy code cho tôi một trang web tên là "Ví VNM" có giao diện ngân hàng, có effect cho người dùng nhét thẻ vào và bắt người dùng nhập tên của mình vào, trong đó sẽ hiển thị số dư, các nút để chuyển tiền, nạp tiền vào ví, xem số dư, mua dịch vụ bằng số dư trong ví, 1 vài minigame đơn giản, làm giao diện đẹp, tối giản, UI UX mượt, đẹp, tạo cảm giác sang trọng và mượt mà, ngoài ra làm nổi bật quy tắc "Không Ba" của ví, 3 quy tắc đấy tôi sẽ thêm vào sau, chỉ cần để placegholder và design nó đẹp trước là được
